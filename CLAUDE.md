# Claude Code instructions

Read AGENTS.md first. It explains how the site, the TinaCMS editor, the images and the deploys fit together, and sets the rules every change follows: a GitHub issue with a plan, tests on both phone and desktop, approval, then deploy.

@AGENTS.md

## Skills in this repo

- `setup`: get the site, editor and tests running on a new machine.
- `add-work`: add a folder of images as a new series or to an existing one.
- `add-writing`: add a page of writing.
- `site-change`: the issue, build, test, approval and deploy workflow for any change.

- `write-in-mika-voice` and `check-mika-text`: draft and check site text in Mika's voice, from the taste package in `taste/`.
- `write-site-issue`: write the GitHub issue for a change.
- `review-change`: review a change before asking for approval.
